# **一、合板吉他、面单吉他、全单吉他的区别**


**1.合板、面板、全单吉他的定义。**


（1）合板吉他：也称夹板，是由三层木皮加压成型


的；


（2）面单吉他：指面板是实木，背板、侧板都是合板


的；


（3）全单吉他：指面板、背板、侧板全都是实木。


**2.关于它们的音色、价格。**


**音色好坏：** 合板﹤面单﹤全单



<img src="/img/吉他.pdf-0-0.png">0-0
合板由于是多层的压合板材，震动在不同的介质之间的


传递会有很大程度上的损耗，所以来自弦的震动在传递


给面板之后会迅速的衰弱，到达共鸣箱的时候其实已经


被削弱了很多，因此音色音量上都远不如单板。对于单


板和合板来说，首先单板就是一整块木头，而合板一般


是3层木头粘合在一起的，所以从声音传导方面肯定单


板要好。而全单则是三块整块（面、背、侧）的木头，


声音的传导相对于合板、单板是最好的，所以音色音量


方面在三者中是最好的。


**价格高低**


合板﹤面单﹤全单


**3.如何辨别？**



<img src="/img/吉他.pdf-1-0.png">1-0
**（1）听音色**


合板琴的木材是压缩成型的，再加上胶水粘合，共振不


如自然木材，因此声音比较沉闷，而且延音较短；单板


琴声音极具动态，演奏时延音较长，音色动听。全单琴


的共振在三者中是最好的，声音的表现力也是最强。但


是这种方法对于不会弹琴的初学者来说是很难做到的，


我们可以用下面的方法。


**（2）看音孔**


①合板琴面板是由3层木头合成的，所以音孔处面板的


横切面是没有相对应的纹路的。


②单板琴面板是由一整块木头做成的，所以面板横切面


纹路清晰可见，并且纹路相对应。



<img src="/img/吉他.pdf-2-0.png">2-0
<img src="/img/吉他.pdf-3-0.png">3-0

③全单琴它的面板、背板、侧板都是由一整块的木头制


成的，所以它们都有相对应的纹路。面板的鉴别参考面


单琴，侧板和背板，你们可以通过音孔看下内部的纹


路，再找下外部的纹路，看它们是否是相对应的；


还有一个方法，把吉他拿到黑暗的地方，拿着手电筒从


音孔胴身内部照，然后从外部观察是否会透光，会就是


实木的，因为它是一块单一的木材做成的，所以会透


光；


第三种方法，教大家一个小窍门，全单琴的侧板内部和


背板一般都会有加强片，目的是加强背侧板的稳定性，


可以看下图：

4.另外要说明，其实就全单、单板和合板而言，全单比


单板好，单板比合板好只是在两者是同一等级的木头上


而定论的。也就是说，木材等级越高的合板，它反而比


木材等级较低的单板还要好。另外，吉他的配置、制作


工艺等也会影响吉他的好坏。

# **二、常见的吉他面板材质及特点**


**1.云杉（SPRUCE白松）**


云杉是吉他面板使用最多的一种木材，木纹偏大，音色


大气、浑厚，更有方向感，能更好的反射演奏的力度和


强度，层次丰富，清晰度高。


云杉的种类有多种，包括：


(1)西提卡云杉(SITKA SPRUCE)


西提卡云杉木生长于北加利福尼亚州及阿拉斯加之间，


学名Picea Sitchensis，这种木材在强度以及弹性上的


表现都不错。


**音色上：** 西提卡云杉具有相当高的韧性和较轻的重量，


正是高声音速率材质的要求。这让它拥有充满力道和反


应直接的音色，并且在大力弹奏时，也能保证声音足够


清澈。对于那些对动态反应要求高的乐手而言，西提卡


是第一手选择。但是，西提卡缺乏足够强大的泛音，当


用较小力道弹奏的时候，它产生的音色便较为单薄。它


拥有清亮的音色，优秀的动态表现，适合节奏性强的曲


风。


<img src="/img/吉他.pdf-6-0.png">6-0

(2)英格曼云杉(ENGELMANN SPRUCE)


英格曼云杉生长于北美西部。学名Picea


Engelmannii。它拥有精细、均匀、笔直的纹理。重量


轻，硬度低，容易加工。


**音色上：** 英格曼的基础音色较为微弱，但在泛音的表现


上十分强壮并且范围较广。因此，相对于西提卡，英格


曼对于那些需要多样化并且较为丰富音色的乐手而言，


英格曼是第一手选择，尤其是在弹奏力道较为轻柔的时


候，他提供的温和的泛音共鸣令人神往。但是缺点在于


当大力弹奏时，它的音色清晰度以及鲜明度就被牺牲


了。


<img src="/img/吉他.pdf-7-0.png">7-0

（3）欧洲云杉(EUROPEAN SPRUCE)


欧洲云杉生长于欧洲北部和中部。学名Picea Abies。


拥有与英格曼类似，但是更加深邃的纹理。因此经常与


英格曼混淆。


**音色上：** 欧洲云杉的潜力很大，需要足够长的时间开


声，拥有与英格曼类似的特色，并且拥有不错的音色饱


满度。但是欧洲云杉在动态反应上的表现差强人意。因


此适应的风格比较广泛。


<img src="/img/吉他.pdf-8-0.png">8-0

（4）阿迪朗达克云杉(ADIRONACK SPRUCE)


阿迪朗达克云杉生长于美洲东北部。重量较重，声音速


率高，在所有制作吉他的材料中，阿迪朗达克是硬度最


高的。


**音色上：** 它拥有十分强壮的音色，同时还拥有多样化的


泛音表现，在各种材料中，阿迪朗达克拥有最大的音量


表现，并且拥有丰富的饱满度，使得各种动态范围下的


弹奏都能保持清澈的音色。被誉为吉他面板的圣杯。


<img src="/img/吉他.pdf-9-0.png">9-0

**2.红松（CEDAR雪松）**


红松生长于美国与加拿大西北部近太平洋地区，木理通


直，呈红棕色。使用频率较多。使用红松作为面板的吉


他通常音色松软、温暖，对演奏力度的反应较快，声音


比较发散，并朝各个方向辐射，好的制作家可以将云杉


做的更温暖，红松做的更凝聚！


**音色上：** 红松可以提供较佳的泛音，较弱的基础音色，


给人十分柔和的感觉，并且开声期很短。但是它在接近


动态边缘的时候经常缺乏音色的清晰度，偶尔音色会闷


若如泥。


<img src="/img/吉他.pdf-10-0.png">10-0

**3.桃花芯木(MAHOGANY)**


桃花芯木为浅红褐色，径切面具有美丽的特征性条状花


纹，是世界上最名贵的木材之一。桃花芯木具有密度适


中，尺寸稳定性好，韧性强等优点，易于加工制作。桃


花芯木单独做面板比较少见，一般出现在全桃花芯木的


吉他里。


**音色上：** 桃花芯木重量较重，质地中等，做成吉他后一


般富有饱满温暖的中音，低音干净清晰且有力度，由于


木质的特点。所以整体声音有种“紧实”的感觉。


<img src="/img/吉他.pdf-11-0.png">11-0

**4.相思木（KOA夏威夷洋槐）**


相思木来自夏威夷，是一种稀有木材。使用频率不多。


它的纹路非常漂亮，经常呈火焰状。相思木做面板的吉


他显得十分豪华，音色亮丽，非常突出。


**音色上：** 相思木具有温暖而厚重的音色特质，类似于桃


花心木，中频有力，穿透性好，高频明显更为优秀，可


以说相对于桃花芯木有过之而无不及。


另外，还有一种来自台湾的相思木，叫台湾相思木


（Taiwanese KOA）。台湾相思木在声音的颗粒感、


通透性上面比夏威夷相思木差一些，价格也相对比较


低。
